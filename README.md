# Indoor Net Booking

A frontend web application for booking indoor cricket nets.  
Built using HTML, CSS, and JavaScript with form handling and basic UI flow.

## Tech Stack
- HTML
- CSS
- JavaScript

## Features
- Indoor net booking form
- User signup and contact pages
- Simple admin page layout
- Responsive UI improvements
- Static frontend-only implementation

## Pages Included
- Home / Booking page
- About page
- Contact page
- Sign up page
- Admin page (UI only)

## How to Run
1. Clone the repository
2. Open `index.html` in any browser
3. Use the forms to simulate booking flow

## Note
This is a frontend-only project created for learning and practice purposes.  
No backend or database is connected.
